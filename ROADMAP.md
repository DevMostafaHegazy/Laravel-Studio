# Roadmap

The roadmap is a direction, not a promise. Priorities are driven by real Laravel
workflows, accessibility, and keeping the core free and local-first.

## Near term

- Finish splitting project inspection and Artisan coordination into dedicated
  backend collaborators without changing the RPC contract.
- Add keyboard-only navigation tests for the project panel and dashboard.
- Add disposable-versioned screenshots for the README and release notes.
- Improve first-run guidance inside the empty explorer view.
- Add signed Windows and macOS release instructions with a documented update
  path.

## Later

- Test-runner selection beyond the default Artisan test command.
- Richer Blade and Livewire navigation.
- Optional workspace-level checkpoints for common maintenance actions.
- Better support for custom Laravel project layouts.

## Explicit non-goals

- Uploading project source or environment files to a hosted service.
- Requiring an account or paid key to use the core editor.
- Reimplementing the Theia editor, terminal or extension host.
