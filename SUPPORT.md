## Bugs and feature requests

Search the [existing issues](https://github.com/DevMostafaHegazy/Laravel-Studio/issues)
before opening a new one. Use the bug or feature request template and include
your operating system and Laravel Studio version.

## Security

Do not report vulnerabilities in a public issue. Use the
[private security advisory flow](https://github.com/DevMostafaHegazy/Laravel-Studio/security/advisories/new)
described in [SECURITY.md](SECURITY.md).

## Community

Use [GitHub Discussions](https://github.com/DevMostafaHegazy/Laravel-Studio/discussions)
for setup questions, workflows and ideas that are not yet concrete issues.
